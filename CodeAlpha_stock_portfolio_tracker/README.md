Stock Portfolio Tracker 📈

Description

The Stock Portfolio Tracker is a simple Python project that calculates the total value of a user's stock investments. Users enter stock names and quantities, while the program uses a predefined dictionary of stock prices to compute the total investment value. The final result can also be saved to a ".txt" or ".csv" file for future reference.

Features

- User inputs stock names and quantities
- Uses a predefined dictionary for stock prices
- Calculates total investment value
- Displays portfolio summary
- Optionally saves results to a ".txt" or ".csv" file
- Simple console-based interface

Technologies Used

- Python
- Dictionary
- Input/Output
- Arithmetic Operations
- File Handling (.txt / .csv)

How to Run

1. Install Python on your system.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Python IDE.
4. Run the Python file:
   python stock_portfolio_tracker.py

Learning Outcomes

This project helps beginners understand:

- Python dictionaries
- User input handling
- Basic arithmetic operations
- File handling
- Console-based application development
